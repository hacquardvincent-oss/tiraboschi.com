Comment ça fonctionne

TIRABOSCHI Paris
à l'international

Cette page présente l'ensemble des composants d'internationalisation du site. Basculer entre les marchés avec les boutons en haut pour visualiser chaque contexte : devise, langue, bannière géolocalisation, notices fiscales et sélecteurs de locale.

01
Bannière Géo
Apparaît automatiquement quand l'IP détectée ne correspond pas au marché actif. Slide depuis le haut. Propose de basculer vers la bonne devise. Dismissable, mémorisé en session.
02
Sélecteur Header
Chip discret (drapeau + code devise) dans les actions header. Dropdown au clic avec tous les marchés. Sur mobile : dans le drawer navigation, en bas de liste.
03
Prix dynamiques
Tous les prix s'actualisent lors du changement de marché. Transition opacité 0→1 pour éviter un flash brutal. Code devise affiché après le montant.
04
Labels multilingues
FR · EN · JA · KO · AR. Tous les labels UI s'adaptent à la langue du marché. Support RTL complet pour l'arabe (dir="rtl" sur document).
05
Notices fiscales
FR/EU : Prix TTC. UK : excl. VAT. USA : excl. taxes. JP : 税込 (TTC). Mentions livraison offertes adaptées à chaque marché.
06
Sélecteur Footer
14 pays disponibles, 5 langues. Selects style underline (pas de boîte). Bouton valider → change de marché. Toujours visible en bas de chaque page.
